# קורס התאחדות מתקדמים 3 · מפגש א: זכויות בנייה, חלופות והתאמה

ממשק הוראה לבדיקת זכויות בנייה לפי תב"ע: מיפוי זכויות, בניית מודל וחלופות, ובדיקת התאמה מול העירייה והיזם.

## מצב נוכחי
- `public/index.html`: מוקאפ סטטי של מפגש א. הערכים בו דמו בלבד ולא נשלפו מתב"ע אמיתית.
- `docs/spec.md`: אפיון השלבים, הקלט, הפלט וכללי הבדיקה. המקור לכל שינוי.
- `docs/prompts.md`: פרומפטים להעתקה, בעברית ובאנגלית. כל פרומפט עצמאי ולא תלוי בקבצים בריפו.

## הרצה מקומית
פתחי את `public/index.html` בדפדפן. אין צורך בהתקנה.

## פריסה
הריפו מחובר ל-Vercel. כל מיזוג ל-main נפרס אוטומטית.

## הקשר
ענת דוד שטיבלמן, אדריכלית העיר אשדוד. הקורס מיועד לאדריכלים שבונים כלי AI בעצמם.
